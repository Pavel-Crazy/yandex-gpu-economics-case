# Экономика инференса GLM-5.2 в Sail Research

При зафиксированных вводных слайда получаем **$51,46/ч выручки**, **$21,04/ч стоимости GPU**, **59,11% GPU contribution margin** и **$6,4323545/GPU·ч break-even**. Это условная экономика расчётного узла при непрерывной продаже 100% выбранного benchmark-throughput.

**Это GPU contribution margin, не бухгалтерская, валовая или чистая маржа Sail Research, Production-конфигурация Sail не раскрывается - 8×H200 - расчётная конфигурация по публичному benchmark, а не установленный факт о железе Sail.**

## Запуск

Python 3.10+. Скрипту достаточно стандартной библиотеки:

```bash
python3 src/case_2_sail_glm52_economics.py --check-slide
python3 src/case_2_sail_glm52_economics.py --check-slide --json
```

Для выполнения Notebook из корня распакованного репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m nbconvert --to notebook --execute --inplace notebooks/case_2_sail_glm52_economics.ipynb
```

В Windows активация: `.venv\Scripts\activate`. Установка зависимостей требует сети; последующие расчёты работают локально. Notebook можно открыть любым Jupyter-совместимым редактором. Команда nbconvert выполняет все ячейки через настоящее Python-ядро и сохраняет outputs; она не запускает GPU-benchmark заново.

Произвольный сценарий: измените копию CSV и передайте `--assumptions path/to/assumptions.csv`. При намеренном изменении сценария запускайте без `--check-slide`: этот флаг специально проверяет исходные контрольные значения слайда.

## Вводные и формулы

| Параметр | Значение |
|---|---:|
| Вход, USD / 1 млн токенов | 0,50 |
| Выход, USD / 1 млн токенов | 3,15 |
| Профиль запроса | 8192 input + 1024 output |
| Узел / точность модели | 8×H200 / GLM-5.2 FP8 |
| Total throughput всего узла | 17 992,6 input+output tok/s |
| Базовая ставка | 2,63 USD/GPU·ч |
| Доля реализованного benchmark-throughput | 100% |

Пусть `I, O` — токены запроса, `Pi, Po` — цены за миллион, `T` — total throughput, `u` — доля реализованного throughput, `N` — число GPU, `p` — ставка аренды.

```text
Выручка запроса = (I × Pi + O × Po) / 1 000 000 = $0,0073216
Запросов/с     = T × u / (I + O)              = 1,9523220486
Запросов/ч     = Запросов/с × 3600             = 7028,359375
Выручка/ч      = Запросов/ч × Выручка запроса   = $51,458836
GPU-cost/ч     = N × p                        = $21,04
Contribution/ч = Выручка/ч − GPU-cost/ч         = $30,418836
GPU-маржа      = Contribution/ч / Выручка/ч     = 59,112950%
Break-even     = Выручка/ч / N                 = $6,4323545/GPU·ч
```

**Нельзя считать 17 992,6 выходными токенами/с:** это сумма input и output. При профиле 8:1 выход составляет около 1999,18 tok/s. Нельзя умножать total throughput целиком на выходной тариф или ещё раз умножать производительность на 8 GPU.

## Методологические ограничения

- Benchmark — авторский измеренный результат по протоколу SGLang, не официальный production-benchmark Sail. Выбран balanced c=64, 128 запросов на случайных данных, MTP 1-1-2. Автор указывает, что высокий acceptance на случайных данных не репрезентативен для реальных запросов. Для выбранной строки TTFT p50 ≈7,74 с, p99 ≈12,31 с; перенос throughput на другой SLA требует нового измерения. Последующие строки отчёта имеют другие параметры и не подменяют выбранную точку.
- База предполагает достаточный спрос и непрерывную продажу benchmark-throughput. Доля `u` — отношение фактически оплаченного throughput к benchmark, а не аппаратная загрузка из GPU telemetry. При фиксированной аренде $2,63 безубыточность достигается примерно при **40,89%** benchmark-throughput. В Notebook есть сценарии 100%, 75%, 50% и 40%.
- Отдельные CPU, сеть, хранение, резерв мощности, персонал, комиссии, налоги и прочие расходы не добавлены. Публичная цена аренды узла может уже включать часть инфраструктуры, поэтому $21,04 — proxy стоимости аренды, а не измеренная себестоимость одних чипов Sail. Двойной учёт этих расходов тоже недопустим.
- Вход считается без кеш-скидок; output включает все оплачиваемые выходные токены. Дополнительные reasoning-токены сверх 1024, скидки, бесплатные кредиты и потери выручки не моделируются. Другой профиль требует другого измерения throughput.
- Диапазон цен отдельных GPU не гарантирует доступность связного 8-GPU узла с нужными NVLink, регионом и SLA. Все суммы — USD; сравниваются арендные ставки, не CAPEX и амортизация.

Результат отвечает на условный вопрос: покрывает ли выручка при выбранных тарифах и производительности принятую стоимость аренды? Для этих вводных — да. Фактическую прибыль Sail этот расчёт не устанавливает.

## Проверки

`--check-slide` проверяет все четыре KPI на точности слайда, четыре сценария и точный break-even. Notebook дополнительно сравнивает пошаговые формулы с модулем и JSON отдельного запуска скрипта, проверяет отрицательную маржу выше break-even. Итоги реального выполнения сохранены в `validation/report.md`.
